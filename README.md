## Project Overview
**Course:** Web Application Development
**University:** Tech University of Korea (TUK)

This repository contains practice code created while studying Web Application Development.

The purpose of this project is to:

- Practice web page layout and styling with HTML5 and CSS3
- Build interactive UI components with JavaScript and jQuery UI (accordion, tab panels, menu bar, popups)
- Learn server-side web development with JSP and MySQL

---

## Features

This repository includes examples that demonstrate:

- Static web page design and styling (HTML/CSS)
- Interactive jQuery UI components (Accordion, MenuBar, TabPanels)
- Popup windows and layered navigation menus
- Responsive/mobile-friendly web layout techniques
